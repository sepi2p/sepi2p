## Featured projects

### 🎬 [Research Explainer](https://github.com/sepi2p/research-explainer-skill)

An open-source **Claude Code skill** (also packaged for Codex) that turns research papers and experimental results into mathematical explainer videos and optional slides, in **English or Persian**.

- Creates Manim animations using figures grounded in real experiments.
- Tracks claims and on-screen numbers back to their sources.
- Supports Persian right-to-left typesetting, subtitles, and multiple voice workflows.
- Includes example projects and documented testing limits.

[Explore the skill, see demos, and install it →](https://github.com/sepi2p/research-explainer-skill#readme)

### 🔬 [Hidden-Jacobian Mobility in Adversarial Trajectories](https://github.com/sepi2p/hidden-jacobian-routing-research)

Research code and reproducibility materials for studying adversarial trajectories, hidden-Jacobian motion, and the effects of initial attack difficulty. Includes experiment scripts, split registries, audit checks, and lightweight result summaries.

[Explore the research code →](https://github.com/sepi2p/hidden-jacobian-routing-research#readme)
